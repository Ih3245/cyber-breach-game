## 🎮 Game Overview
- **Engine:** Pure HTML5 Canvas (60+ FPS, HiDPI Retina support, dynamic delta-time physics).
- **Sound System:** Real-time Web Audio API procedural sound synthesizer (weapons, explosions, dash swooshes, level-up fanfares, and an adaptive bassline).
- **4 Distinct Weapon Classes:**
  1. **Pulse Blaster:** Rapid twin cyan bolts with pinpoint accuracy.
  2. **Scatter Cannon:** Devastating 7-pellet spread with heavy kinetic knockback.
  3. **Hyper Railgun:** High-velocity linear piercing beam.
  4. **Plasma Launcher:** Ballistic explosive orb with an expanding AoE shockwave.
- **12 Roguelite Overclock Perks:** Randomized 3-card upgrades upon collecting cyber-energy cores (Fire rate overclock, Nova dash, Cryo injection, Chain lightning, Aegis barrier, Thorium rounds).
- **Apex Boss Battles:** Multi-phase titan boss encounters with bullet hell spirals and radial shockwaves.
- **Tactical Radar:** Real-time circular minimap tracking hostiles, cyber-cores, and boss signatures.

## 🕹️ Controls

| Key / Input | Action |
| :--- | :--- |
| `W` `A` `S` `D` / `Arrow Keys` | Move Interceptor Craft |
| `Mouse Aim` + `Left Click (LMB)` | 360° Aim & Fire (Hold to auto-fire) |
| `Spacebar` / `Right Click (RMB)` | Hyper-Dash with invincibility frames |
| `1` `2` `3` `4` / `Mouse Wheel` | Tactical Weapon Switching |
| `Escape` / `P` | Pause Mission / Tactical Menu |
| Top-Right HUD Audio Button | Toggle Synthesizer Audio On/Off |
